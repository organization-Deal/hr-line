# P10.45 — เอกสารหลังเงินเดือน ใต้ Payroll

แพตช์เฉพาะไฟล์ที่เพิ่มหรือแก้ไข ลงทับ P10.44 ตามโครงสร้างโฟลเดอร์เดิม ไม่ต้อง migrate ฐานข้อมูล หลังอัปเดตกด Ctrl+Shift+R แล้วดู UI P10.45

## ใช้งาน

เมนูด้านซ้าย **Payroll → เอกสารหลังเงินเดือน**

- ย้ายทางเข้าจากปุ่มบนหน้า Payroll มาเป็นเมนูย่อยใต้ Payroll
- เปิดเป็นหน้าเต็ม เลือกรอบเงินเดือนได้ในหน้านี้โดยตรง ไม่ต้องเลือกจากหน้า Payroll ก่อน
- เอกสารรายเดือน รายปี / 50 ทวิ และตั้งค่านำส่ง ใช้ workflow เดิม
- ปุ่ม “กลับ Payroll” กลับไปทำเงินเดือนตามปกติ
- ทางเข้าจากปุ่มอื่นที่เรียกเอกสารเดิม จะเปิดหน้าใหม่นี้เช่นกัน

การเลือกรอบเอกสารแยกจากรอบที่กำลังทำเงินเดือน ป้องกันผลตอบกลับล่าช้าจากรอบหรือบริษัทเดิมมาแทนหน้าปัจจุบัน สิทธิ์เข้าถึงใช้บทบาท Payroll เดิม และการเปิด/สลับรอบไม่สร้างเอกสารหรือบันทึกสถานะให้อัตโนมัติ

## ตรวจสอบ

- Chromium: เมนูอยู่ใต้ Payroll, สถานะเมนูและชื่อหน้า, เปิดตรงโดยยังไม่มีรอบที่เลือก, ไม่เปิด dialog ซ้อน
- เลือกรอบ เปิดเอกสารรายเดือน/รายปี/ตั้งค่า และบันทึกตั้งค่าพร้อม period_id ที่เลือกจริง
- การแยกข้อมูลจากหน้า Payroll, คำขอที่ตอบช้า, สลับบริษัท, สิทธิ์ไม่เพียงพอ, ไม่มีรอบ, โหลดล้มเหลวและลองใหม่
- ขนาดจอ 1440 / 768 / 390 / 320px และแก้แท็บไม่ให้ล้นหน้าบนจอเล็ก
- Regression workflow เอกสารเดิมผ่าน รวมสร้างไฟล์ ดาวน์โหลด บันทึกตั้งค่า และตรวจเหตุผลเมื่อแก้ฐานค่าจ้าง
- npm run check, module syntax checks และ release test ผ่าน

ใช้ API จำลองในการทดสอบหน้าเว็บ ไม่ได้ส่งข้อมูล ยื่นเอกสาร หรือเปลี่ยนข้อมูล production การส่งหน่วยงานยังเป็นการ Export แล้วผู้ใช้นำไปยื่นเองตามขั้นตอนเดิม
