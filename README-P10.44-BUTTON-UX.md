# P10.44 — Button UX audit

แพตช์เฉพาะไฟล์ที่เปลี่ยน ลงทับ P10.43 โดยคงโครงสร้างโฟลเดอร์เดิม ไม่ต้อง migrate ฐานข้อมูล หลังอัปเดตกด Ctrl+Shift+R แล้วดูเลข UI P10.44

## สิ่งที่แก้

- ปุ่ม “ดูสถานะใบลาเพิ่มเติม” ถูกสร้างบนจอคอม แต่มีสไตล์เฉพาะมือถือ จึงเป็นปุ่มเทาดั้งเดิม และไม่มีข้อมูลเพิ่มให้เปิดเพราะคอมแสดงครบอยู่แล้ว: ซ่อนปุ่มนี้บนคอม
- มือถือใช้ข้อความ “ดูสถานะใบลาทั้งหมด” / “แสดงเฉพาะยอดหลัก” พร้อมกรอบ ขอบมน ลูกศร สถานะเปิด/ปิด และพื้นที่กดอย่างน้อย 44px
- ซ่อนปุ่มขยายสถานะเมื่อยังไม่มีข้อมูลหรือมีสถานะไม่เกินสามการ์ด พร้อมอัปเดตตามข้อมูลและขนาดจอ
- ปุ่มขยายยอดเงินเดือน ปุ่มดูรายละเอียด/ประวัติในตาราง ปุ่มเพิ่มเติมรายพนักงาน ปุ่มเปลี่ยนรอบ และปุ่มหลัก/รอง/ข้อความในหน้าและกล่องโต้ตอบ มีพื้นที่กดบนมือถืออย่างน้อย 44px
- ปุ่มหลัก/รองจัดข้อความและไอคอนกึ่งกลาง พร้อมรองรับข้อความยาว
- เพิ่มพื้นที่ปุ่มปิดเมนูมือถือเป็น 44px และเปลี่ยน cache keys ของไฟล์ที่แก้

## การตรวจ

ใช้ HTML/CSS และตัวควบคุม UI จริงผ่าน Chromium กับข้อมูลจำลอง ไม่เรียก API production:
- 1440, 1024, 768, 720, 390 และ 320px
- ตรวจปุ่มที่แสดงในแต่ละหน้าแดชบอร์ดรวม 3,708 การแสดงผล ไม่พบปุ่มที่ยังใช้กรอบ outset ดั้งเดิมของเบราว์เซอร์
- เปิด/ปิดสถานะลาและยอด Payroll, คีย์บอร์ด Enter/Space, focus, empty state, disabled และขนาดพื้นที่กดในตาราง/กล่องโต้ตอบ
- ไม่พบ JavaScript error ใน fixture; npm run check และ release version test ผ่าน

ขอบเขต: ตรวจโครงหน้าแดชบอร์ดและตัวควบคุมที่ระบุ พร้อมตัวอย่างตาราง/กล่องโต้ตอบ ไม่ใช่การทดสอบทุกธุรกรรมกับข้อมูล production ไม่มีการเปลี่ยนสิทธิ์ การคำนวณเงินเดือน หรือข้อมูลการลา
