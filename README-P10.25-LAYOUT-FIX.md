# P10.25 Layout Fix

ใช้วางทับ P10.25 ที่ติดตั้งแล้ว เปลี่ยนเฉพาะ public/index.html และ public/ui/access.css

แก้ workspace ที่เป็นลูกของ CSS grid แต่กำหนดเพียง max-width กับ margin:auto จึงหดความกว้างตามเนื้อหาและลอยอยู่กลางจอ
กำหนด width:100%, min-width:0, justify-self:start และ margin:0 ให้ชิดแนวซ้ายเดียวกับพื้นที่ตั้งค่า จำกัดความกว้างสูงสุด 1200px
จัดแถวรายชื่อเป็น grid ให้รูป ชื่อ บทบาท และปุ่มอยู่แนวเดียวกัน ลดความสูงและช่องว่างที่ไม่จำเป็น
จอแคบย้ายบทบาท/ปุ่มลงใต้ข้อมูลของแต่ละคน ไม่บีบชื่อและอีเมล

วางทับไฟล์ตามโครงสร้างเดิมแล้ว Deploy หน้าเว็บ ไม่ต้องลบไฟล์หรือรัน migration
index.html เปลี่ยน cache key ของ access.css เป็น P10.25-layout2 เพื่อให้ดึง CSS ใหม่
ป้าย UI ยังคง P10.25 เพราะเป็นแพตช์ layout ไม่เปลี่ยน JavaScript/API/สิทธิ์ผู้ใช้งาน

ตรวจ regression สิทธิ์ 38 จุดและ release test ผ่าน ไม่มีการแก้ข้อมูลผู้ใช้งานจริง
ยังไม่ได้ทดสอบการจัดวางจริงในเบราว์เซอร์หรือ Deploy ให้
