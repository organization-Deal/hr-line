# Nakna P10.27 — มือถือและลดงานโหลดที่ซ้ำกัน

ฐาน: P10.25 หรือ P10.26 (รวม Employee Service, กรอบวันหยุด, layout สิทธิ์ และแท็บรอจัดการจาก P10.26 แล้ว)

วิธีอัปเดต
1. วางไฟล์ใน public/ และ src/ ทับไฟล์เดิมตามโฟลเดอร์ ห้ามวาง public ไว้ใน public อีกชั้น
2. Deploy Worker พร้อม static assets ในครั้งเดียว ไม่ต้องลบไฟล์เดิมหรือเพิ่ม migration ฐานข้อมูลสำหรับแพ็กนี้
3. เปิดเว็บใหม่แล้วตรวจเมนูด้านข้างต้องเป็น UI P10.27 ถ้ายังเป็น P10.25/26 ให้ตรวจ deployment และรีโหลดหน้า
4. tests/ เป็นชุดตรวจโค้ด ไม่ต้องนำไปตั้งเป็นเว็บไซต์

สิ่งที่เปลี่ยน
- เปลี่ยนหน้าแล้วกลับด้านบนทันที ทั้งตัวหน้าและ main scroller แทนการเลื่อนนุ่มที่อาจชนกับการเปลี่ยนความสูงของหน้า
- ปุ่มหลัก/รอง/ข้อความในพื้นที่งานและ dialog มีพื้นที่กดอย่างน้อย 44px บนมือถือ
- เพิ่มพื้นที่กดสวิตช์เป็น 44px โดยคงรูปสวิตช์ขนาดกระชับ
- ช่องกรอกบนมือถือใช้ 16px ลดปัญหา iPhone ซูมตอนแตะช่องกรอก
- Employee Service ใช้การ์ดสรุป 2 ช่องและแถวประกาศเต็มความกว้าง แท็บอ่านง่ายขึ้น และเรียงรายละเอียดเรื่องถึง HR เป็นแนวตั้ง
- เพิ่มความชัดเจนของข้อความประกอบ Dashboard และการแจ้งเตือน
- รวมเฉพาะ GET ที่กำลังขอพร้อมกันและตรงเงื่อนไขให้เหลือคำขอเดียว ไม่เก็บผลสำเร็จเป็น cache เพิ่ม
- คำขอแยกตามผู้ใช้/บริษัท/timeout/สถานะ silent และเลิกใช้คำขอร่วมทันทีเมื่อมีการเขียนข้อมูล
- หยุด preload ข้อมูลพนักงานบนจอมือถือ โหมดประหยัดข้อมูล 2G หรือเมื่อกำลังใช้หน้าอื่น
- preload บางส่วนไม่ทำเครื่องหมายหน้าพนักงานว่าโหลดครบแล้ว เพื่อไม่ข้ามคำเชิญและสถานที่ทำงาน
- Dashboard อ่านเฉพาะช่องข้อมูลพนักงานและผู้สมัครที่ใช้ ไม่อ่านเงินเดือน/ข้อมูลผู้สมัครทั้งแถว และรวมวันลา/ตารางงาน/วันหยุดไว้ใน batch แรก
- ป้องกันผล Dashboard/People และ company profile ที่ล่าช้าจากบริษัทก่อนหน้ามาเขียนทับหลังเปลี่ยนบริษัท

การตรวจ
- ผ่าน 438 checks ในชุด mobile/performance, Dashboard, Employee Service, Loading, Payroll, Access, Notifications, feature sources และ full card preview พร้อม syntax check และ release label
- ชุดใหม่ทดสอบคำขอซ้ำ การแยกบริษัท/ผู้ใช้ การอ่านหลังเขียน การลองใหม่ การคัดลอกผลแยกผู้เรียก และ SQL ทั้ง 8 คำสั่งกับ SQLite ที่ใช้ migration จริง
- ตรวจเว็บก่อนแก้ที่หน้าจอจำลอง 360/390px โดยเว็บขณะตรวจยังเป็น P10.25
- ยังไม่ได้ Deploy แพ็กนี้หรือทดสอบบน Safari/iPhone จริง จึงยังไม่ระบุตัวเลขความเร็วหลังแก้
- ไม่มีการส่ง LINE จริง อนุมัติรายการ หรือเปลี่ยนข้อมูลเงินเดือนจากการทดสอบ
