ต่อจาก P10.12 ในแชตนี้ / ส่งเฉพาะ 6 ไฟล์ที่เพิ่มหรือแก้

ติดตั้ง
1. อัป public/ และ tests/ ทับตาม path เดิมใน Repository อย่าเอาไฟล์ใน public ไปวาง Root
2. รอ Cloudflare Deploy สำเร็จ แล้ว Ctrl+Shift+R
3. เมนูสวัสดิการต้องมีหัวข้อ สวัสดิการของทีม และป้าย UI P10.13
ไม่ต้องลบไฟล์ ไม่ต้อง Migration ไม่มี src/index.js ในชุดนี้
ถ้ามีการแก้ app.js/index.html เพิ่มนอกแชตหลัง P10.12 ให้เทียบไฟล์ก่อนทับ

สิ่งที่เปลี่ยน
- สรุป 3 ตัว: สวัสดิการเปิดใช้ / คนที่มีสิทธิ์วันนี้ (ไม่นับซ้ำ) / สวัสดิการที่ยังไม่มีผู้มีสิทธิ์วันนี้
- นับสิทธิ์ตามวันเริ่ม วันสิ้นสุด และสถานะ ไม่รวมโปรแกรมที่ปิด
- ขั้นตอนถัดไปสำหรับ HR, ค้นหาสวัสดิการ, ตัวกรอง, รายการและรายละเอียดที่เลือก
- ใช้ภาษาไทยชัดเจน เพิ่มขนาดข้อความ ลดกรอบซ้อนและพื้นที่ว่าง รองรับหน้าจอเล็กด้วย CSS
- เก็บเงินสมทบ 0 ตามข้อมูลจริงในรายละเอียด ไม่ตีความอัตโนมัติว่าไม่เคยตั้งค่าหรือไม่มีค่าใช้จ่าย
- เลือกพนักงานหลายคน / ค้นชื่อหรือรหัส / กรองแผนก / เลือกที่แสดง สูงสุดครั้งละ 50 คน
- ตรวจทานชื่อ สถานะ ช่วงเวลา และหมายเหตุก่อนยืนยัน
- ส่งผ่าน API รายคนเดิมตามลำดับ ไม่มีการเขียนข้อมูลขณะเลือกหรือกดตรวจทาน
- หากบางคนไม่สำเร็จ แสดงรายชื่อ ลองใหม่เฉพาะคนที่ไม่สำเร็จ โดยไม่ส่งซ้ำคนที่สำเร็จแล้วในหน้าต่างเดิม
- ระหว่างส่งข้อมูลป้องกันกดปิดหน้าต่าง; หลังสำเร็จบางส่วนล็อกการกลับไปเปลี่ยนชุดคำขอจนกว่าจะลองส่งจบ
- Owner / Co-owner / HR Admin / HR จัดการได้ตามสิทธิ์เดิม Role อื่นไม่ได้เพิ่มสิทธิ์จากแพตช์นี้
- release.js และ frontend build ดึงรุ่นจากแหล่งเดียวกัน พร้อมคงการแก้หน้าขาวไว้

วิธีใช้
สวัสดิการ → กำหนดผู้ได้รับสิทธิ์ → ค้นหา/กรองแผนก → เลือกพนักงาน → กำหนดสถานะและช่วงเวลา → ตรวจทานสิทธิ์ → ยืนยัน
หากพนักงานมีสิทธิ์ของสวัสดิการนั้นแล้ว การยืนยันจะอัปเดตสถานะและช่วงเวลาตามข้อมูลที่ตรวจทาน
หลังอัปเดต เลือก ดูผู้ได้รับสิทธิ์ เพื่อดูรายการที่บันทึก

ขอบเขต
ไม่ได้เพิ่มระบบคำนวณสิทธิตามกฎหมาย การเบิกจ่าย หรือประวัติการแก้ไขแบบแยกเวอร์ชัน
API เดิมบันทึกหนึ่งรายการต่อสวัสดิการต่อพนักงาน และอัปเดตรายการเดิมเมื่อกำหนดซ้ำ
การส่งหลายคนไม่เป็น transaction เดียว หากปิด Browser/เน็ตหลุด ให้ตรวจรายชื่อที่บันทึกจริงก่อนเปิดกำหนดสิทธิ์ใหม่
ตัวเลือกพนักงานใช้เฉพาะพนักงานสถานะ active ตามระบบเดิม
ยังไม่ได้ Deploy, ยิง API ข้อมูลจริง หรือทดสอบภาพผ่าน Browser/มือถือจริง (ติดตั้ง Browser สำหรับตรวจภาพไม่สำเร็จ)
