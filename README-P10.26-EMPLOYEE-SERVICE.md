# Nakna P10.26 — Employee Service และกรอบวันหยุด

แพ็กเฉพาะไฟล์เปลี่ยนจาก P10.25 รวม Layout Fix และการทำแท็บรอจัดการให้เด่นแล้ว
วางทับตามโครงสร้างเดิม แล้ว Deploy ทั้ง src/ และ public/ ตรวจว่า UI เป็น P10.26
ไม่มีไฟล์ที่ต้องลบ ไม่มี migration ไม่เปลี่ยนข้อมูลหรือสิทธิ์ผู้ใช้งานจริง

## สิ่งที่แก้
พบ CSS ของ Employee Service และวันหยุดมีอยู่แล้ว แต่ HTML ยังไม่ใช้คลาส/โครงสร้างที่ CSS และ JavaScript รองรับ จึงเห็นหน้าเก่าและสรุปวันหยุดหลุดกรอบ

### Employee Service
- ใช้ชื่อ “ศูนย์บริการพนักงาน” และกรอบพื้นที่ทำงานเดียว
- 3 แท็บ: เรื่องถึง HR / ประกาศบริษัท / เมนูบน LINE รองรับคีย์บอร์ด
- ค้นหาหัวข้อ/ชื่อ/เลขเรื่อง และกรองสถานะได้
- เรื่องเร่งด่วนและสำคัญขึ้นก่อน เรื่องปิดแล้วไม่รวมในจำนวนเปิดหรือเร่งด่วน
- สรุปจำนวนประกาศใช้ “ประกาศทั้งหมด” เพราะรวมฉบับร่าง ไม่เขียนว่าทุกชิ้นส่งแล้ว
- ประกาศมีตัวกรองสถานะ แสดงผลส่งสำเร็จ และกดอ่านข้อความเต็มได้
- ย้ายการตั้งเมนู LINE ออกจากคอลัมน์ประกาศไปแท็บของตัวเอง
- แยกสถานะเมนู LINE เฉพาะบริษัทออกจากบริการ LINE นากนะกลาง ไม่ตีความว่าไม่มี LINE บริษัทแล้ว LINE กลางใช้ไม่ได้
- ผู้จัดการไม่เห็นแท็บเรื่องส่วนตัวหรือจำนวนเรื่องส่วนตัว ไม่มีการเพิ่มสิทธิ์ใหม่
- คำขอ HR เดิมยังอยู่ในส่วนกดเปิด ภายใต้แท็บเรื่องถึง HR

### วันหยุดบริษัท
- ใส่คลาสขอบเขต CSS ที่ขาด ให้สรุปวันหยุดและรายการกลับมาอยู่ในกรอบ
- เพิ่มเลือกปีที่แสดงและปุ่มโหลดใหม่ โดยใช้ข้อมูลและตัวกรองปีที่มีในโค้ดเดิม
- จำนวนวันหยุด/มีค่าจ้าง/ไม่มีค่าจ้างยังคำนวณจากปีที่เลือกตามเดิม ไม่เพิ่มหรือลบวันหยุดให้อัตโนมัติ
