# P10.47 People Analytics
ลงทับ P10.46 ตามโครงสร้างโฟลเดอร์ แล้วเผยแพร่ด้วยขั้นตอนเดิมและกด Ctrl+Shift+R ไม่ต้องย้ายฐานข้อมูล

เพิ่มภาพรวมภาษาไทย, วันที่อ้างอิง 30/90 วัน, ประเด็นติดตามและปุ่มไปงานที่เกี่ยวข้อง, สัดส่วนรายการลงเวลาที่สาย, ใบลาอนุมัติและเช็กเอาต์นอกพื้นที่, กราฟพร้อมคำอธิบายสีและศูนย์ไม่มีแท่ง, ตารางทีมค้นหา/เรียง/รวมทีมว่าง, CSV ตามตัวกรอง, คำอธิบาย KPI/การเรียน/สูตร turnover และสถานะไม่มีข้อมูล, รีเฟรชพร้อมสถานะผิดพลาด

ตัวกรองใช้เฉพาะตารางทีม ไม่ใช่ตัวเลือกช่วงวันที่ทั้งหน้า ข้อมูล 30/90 วันตาม API เดิม ไม่มีการเพิ่มการคาดการณ์ลาออกหรือคะแนนความเสี่ยงบุคคล ไม่มีการเปลี่ยนสูตร backend หรือส่งข้อความ LINE ปุ่มติดตามเปิดหน้าระบบเดิม ไม่ได้กรองรายบุคคลให้อัตโนมัติ

ข้อจำกัด: กราฟย้อนหลังอิงวันเริ่ม/สิ้นสุดในทะเบียนและความครบถ้วนข้อมูล; อัตรา turnover เป็นสูตรประมาณการเดิม; วันครบทดลองงานยังไม่ได้รวมใน API จึงไม่แสดงกำหนดสมมติ
