# P9.36 Leave request audit display
ต่อจาก P9.35 + Backend P9.33

แก้เพียง public/app.js และ src/index.js (ไม่ต้อง Migration)

- ตารางใบลา: แสดงเวลายื่นจริงในคอลัมน์วันลา และชื่อผู้อนุมัติจริงพร้อมเวลาตัดสินใจในคอลัมน์ผู้อนุมัติ
- แสดงคนที่ถูกกำหนดให้อนุมัติแยกจากผู้กดอนุมัติจริง
- หน้ารายละเอียดใบลา: เวลา Submit และข้อมูลการตัดสินใจ
- รายงานรายเดือน: เพิ่มเวลา Submit / การอนุมัติ
- เลือกข้อมูลเวลาจาก leave_approval_events; กรณีประวัติเก่าไม่ครบระบุชัดว่าไม่มีข้อมูล
- หลัง HR อนุมัติ โหลดเฉพาะ API ใบลาใหม่เพื่อไม่แสดงผู้กดผิดคน

Deploy ด้วย npx wrangler deploy

หมายเหตุ: P9.35 มี public/app.js ล่าสุด; ใช้ไฟล์นี้ทับ public/app.js ล่าสุด และใช้ src/index.js ที่รวม P9.33
