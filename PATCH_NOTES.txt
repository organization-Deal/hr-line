Nakna HR — P9.23 Payroll Review Excel
=====================================

สิ่งที่เพิ่ม
- กด "ตรวจสอบรอบเงินเดือน" แล้วระบบสร้างไฟล์ .xlsx อัตโนมัติ
- ไฟล์ถูกบันทึกเป็น immutable snapshot ในระบบ ดาวน์โหลดซ้ำได้ภายหลัง
- Sheet "โอนเงิน": รหัส/ชื่อพนักงาน, ธนาคาร, ชื่อบัญชี, เลขบัญชี, Net Pay, วันที่จ่าย, รอบเงินเดือน
- เลขบัญชีบันทึกเป็น Text เพื่อรักษาเลข 0 ด้านหน้า
- Sheet "รายละเอียด Payroll": รายละเอียดเงินเดือน/รายการหัก/Net/ต้นทุนบริษัท
- Sheet "สรุปรอบ": ยอดรวมและข้อมูลรอบ
- แถวที่ข้อมูลธนาคารไม่ครบถูก Highlight และแสดงจำนวนในหน้า Payroll
- ถ้ามีการแก้ Payroll หลังสร้าง Excel ระบบขึ้นสถานะว่าไฟล์เก่าและให้กด "สร้างไฟล์ล่าสุด"
- มีประวัติไฟล์ก่อนหน้าในรอบเดียวกัน
- Excel ที่สร้างตอน Review จะดาวน์โหลดทันที; ถ้า browser/WebView ไม่ยอมดาวน์โหลด ไฟล์ยังอยู่ในระบบให้กดซ้ำได้

ไฟล์ที่เปลี่ยน/เพิ่ม
- src/index.js
- public/app.js
- public/styles.css
- migrations/0035_payroll_review_exports.sql

ติดตั้ง
1) วางไฟล์ตาม path ทับโปรเจกต์ P9.22
2) แนะนำให้รัน: npx wrangler d1 migrations apply DB --remote
   หมายเหตุ: โค้ดมี lazy schema fallback สำหรับ payroll_exports อยู่แล้ว แต่ควรรัน migration เพื่อให้ schema history ตรงกัน
3) รัน: npm run check
4) Deploy: npx wrangler deploy

- migration 0035 SQL syntax: PASS (SQLite smoke)
- XLSX ZIP/XML structure: PASS
