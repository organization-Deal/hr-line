# Nakna P10.32 — แบบสลิปเงินเดือนใหม่

เฉพาะไฟล์เพิ่ม/แก้ไขจาก P10.31-PAYSLIP-HR-SIGNATURE ต้องมีแพตช์ P10.31 ก่อน

## ติดตั้ง
แตก ZIP แล้ววางทับตำแหน่งเดิม รวมไฟล์ใหม่ src/payroll-pdf.js และ Deploy src/public พร้อมกันตามวิธีเดิม
ไม่ต้องลบไฟล์หรือรัน migration เพิ่ม หน้าเว็บแสดง UI P10.32 และ backend P10.32-PAYSLIP-LAYOUT
ยังไม่ได้ Deploy หรือส่งสลิปไป LINE จริง

## รูปแบบใหม่
- หัวเอกสารเป็นชื่อบริษัทจดทะเบียน เลขผู้เสียภาษี ที่อยู่ และโลโก้ที่บันทึกไว้ (หากมี)
- ข้อมูลพนักงาน รหัส แผนก ตำแหน่ง รอบคำนวณ และกำหนดจ่ายจัดเป็นช่องที่อ่านง่าย
- เลขบัญชีแสดงเฉพาะสี่หลักท้าย
- ตารางรายได้และรายการหักวางข้างกัน จำนวนเงินชิดขวาและมีทศนิยมสองตำแหน่ง
- ยอดรายได้รวม รายการหักรวม และแถบเงินรับสุทธิแยกชัดเจน
- ยอดสะสมรายได้ ภาษี และประกันสังคม ใช้ค่าที่เก็บไว้ในรอบนั้น ไม่คำนวณใหม่จากภาพตัวอย่าง หากไม่มีค่าแสดงขีด
- คงลายเซ็น HR ผู้ออกเอกสารพร้อมชื่อ ตำแหน่ง วันที่ ตาม P10.31
- ไม่มีช่องให้พนักงานเซ็นรับเงิน และ “กำหนดจ่าย” ไม่ได้หมายถึงการโอนเงินจริงแล้ว
- ชื่อ/รายการยาวตัดบรรทัด และเอกสารหลายหน้ามีหัวเอกสาร ชื่อพนักงาน รหัส งวด และเลขหน้า
- สูตรเงินเดือน ขั้นตอนยืนยันจ่าย และการเลือกผู้รับ/ส่ง LINE คงเดิม

## เอกสารเดิม
ใช้รูปแบบใหม่กับ PDF ที่สร้างใหม่เท่านั้น ไม่เขียนทับสลิปที่สร้างไว้แล้ว แม้ยังไม่ได้ส่ง
กดสร้างสลิปซ้ำในรอบที่มี PDF ครบแล้ว ระบบยังนำไฟล์เดิมกลับมาใช้ตาม P10.31
แพตช์นี้ไม่ย้อนแก้เอกสารเก่าหรือส่งสลิปอัตโนมัติ
ตั้งค่า HR ก่อนสร้าง PDF ครั้งแรก: Payroll → เครื่องมือเพิ่มเติม → ตั้งค่าลายเซ็นบนสลิป

## ตัวอย่าง
Nakna_P10.32_PAYSLIP_PREVIEW.pdf เป็นข้อมูลบริษัท พนักงาน และลายเซ็นสมมติสำหรับตรวจดีไซน์
