# P10.49 ยกเลิกรอบเงินเดือน
ฐาน P10.48: ลงไฟล์ตามโฟลเดอร์ อัปทั้ง src/ และ public/ แล้วเผยแพร่และ Ctrl+Shift+R ไม่ต้องรัน migration เพิ่ม

เปิด Payroll > เลือกรอบ > เครื่องมือเพิ่มเติมของรอบ > ยกเลิกรอบเงินเดือน
เฉพาะ owner/co_owner ระบุเหตุผล 5–500 ตัวอักษร พิมพ์เดือนให้ตรงและติ๊กยืนยัน ใช้กับ draft/review/locked/published ได้

ยกเลิกแบบเก็บประวัติ: รอบ/items เป็น void, บันทึกจ่ายที่ active เป็น void, เก็บเอกสารและประวัติส่งเดิมและเพิ่ม event พร้อมผู้กระทำ/เหตุผล/เดือนเดิม เปลี่ยน period_key ของรอบเก่าเป็นเดือนเดิม (ยกเลิก #id) เพื่อเปิดเดือนเดิมสำหรับรอบใหม่โดยไม่ลบหลักฐานเดิม สูตร YTD และเอกสารรวมเดิมเลือกเฉพาะ locked/published จึงไม่รวมรอบที่ยกเลิกในการคำนวณครั้งต่อไป

ลิงก์สลิปสาธารณะของรอบที่ยกเลิกแสดงข้อความยกเลิก (410) ไม่เรียกคืน LINE/อีเมล/ไฟล์ที่ดาวน์โหลดหรือยื่นไปแล้ว ไม่คืนเงินธนาคาร ไม่คำนวณรอบถัดไปที่เคยบันทึกไว้ใหม่อัตโนมัติ ผู้ใช้ต้องตรวจยอดสะสมของรอบถัดไปก่อนใช้งาน

ป้องกันข้อมูลข้ามบริษัท/สิทธิ์/stale version, transaction batch รวมสถานะรอบ+การจ่าย+items+event; ยกเลิกไม่ได้ขณะมี lease ส่งสลิป และการ claim ส่งใหม่ต้องตรวจว่ารอบยังใช้งานอยู่

ผ่าน npm run check, test-release-version, test-p10.49-payroll-cancel (SQLite จริงและ handler UI), test-p10.46-payroll-guide-browser (workflow เดิม 5 ขนาด) ไม่ deploy และไม่ส่ง LINE จริงระหว่างทดสอบ
