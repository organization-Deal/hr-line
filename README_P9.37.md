# Nakna P9.37 — Leave Overview

ฐาน: P9.36 (รวม P9.35)

## เพิ่ม
- Dashboard สรุปการลารายพนักงานก่อนส่วนรายงานรายเดือน
- เลือกปีปัจจุบัน / สะสมทั้งหมด; ค้นหาพนักงานและแผนก
- จำนวนครั้งอนุมัติ, จำนวนวัน, จำนวนครั้งแยกประเภท, รออนุมัติ, ไม่อนุมัติ
- รวมพนักงานที่ยังไม่มีใบลา, Export CSV
- API /api/leave-overview ใช้ aggregate SQL ฝั่ง D1 ไม่โหลดรายการใบลาทั้งหมด

## ติดตั้ง
วางไฟล์ public/app.js, public/index.html และ src/index.js ทับตำแหน่งเดิม แล้ว deploy.
ไม่ต้อง migration.

## หมายเหตุ
- นับครั้งจากใบคำขอที่อนุมัติ 1 ใบ = 1 ครั้ง แม้ลาหลายวัน
- กรณีใบลาคร่อมปี ระบบนับทั้งใบในแต่ละปีที่ช่วงวันลาซ้อนทับ (ตัวเลขจำนวนวันของปีนั้นไม่ได้ prorate แบ่งตามปี) ใช้ 'สะสมทั้งหมด' เพื่อดูยอดรวมไม่ซ้ำ
- รายการปฏิเสธไม่รวมยอดลาจริง
- ควรทดสอบกับ Cloudflare/D1 จริงก่อน deploy production
