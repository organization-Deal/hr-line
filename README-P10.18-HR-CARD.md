# P10.18 — คืนการ์ดสรุป HR ให้ตรงกับรูปต้นแบบ

P10.17 เปลี่ยนตัวส่งตามเวลาไปสร้างการ์ดแบบย่อ ทำให้รูปแบบและรายละเอียดไม่ตรงกับการ์ดเดิม รอบนี้แก้ให้ตัวส่งกลางเรียก buildDailyHrStatusFlex ตัวเดิมโดยตรง

## สิ่งที่คืนกลับ

- หัวการ์ด NAKNA · HR DAILY พร้อมพื้นหลัง สี และรูปแบบของ LINE CI เดิม
- หัวข้อ “สรุปทีมรอบ 13:00” โดยเวลาปรับตามค่าที่ตั้งจริง
- ชื่อบริษัท วันที่ไทย และป้ายสถานะทีม
- พนักงาน Active, มีตารางวันนี้, เช็กอินแล้วแบบ 17/28 คน, ลาวันนี้, มาสาย และยังไม่เช็กอิน
- กล่องรายชื่อคนยังไม่เช็กอินเมื่อมีข้อมูล
- งาน HR ที่ยังค้าง: ใบลา เช็กอินย้อนหลัง HR Request เรื่องส่วนตัวตามสิทธิ์ และเอกสารรอลงนามทั้ง HR/พนักงาน
- สถานะว่างเมื่อไม่มีคำขอหรือเอกสารค้าง
- ปุ่ม “เปิด HR Dashboard” และ “สถานะสรุป HR” พร้อมบริษัทที่ถูกต้อง

ยังใช้การตั้งเวลา วัน เปิด/ปิด เลือกผู้รับ และแก้ข้อความจากเมนูการแจ้งเตือนเดิม ข้อความเริ่มต้นไม่แทรกย่อหน้าซ้ำชื่อบริษัท/วันที่ หาก HR เปลี่ยนข้อความเองจะแสดงข้อความนั้นในเนื้อหาของการ์ดเดิม

คงระบบ retry/กันซ้ำของ P10.17 และไม่ส่งเรื่องส่วนตัวให้ผู้รับที่ไม่มีสิทธิ์ ตัวเลขและสถานะยังใช้ข้อมูลจริง ไม่คัดลอกตัวเลขในภาพ

## ติดตั้ง

เป็นไฟล์ที่เพิ่ม/เปลี่ยนจาก P10.17 เท่านั้น แตก ZIP แล้ววางทับตามโฟลเดอร์เดิม จากนั้น Deploy Worker ทั้ง src และ public ผ่านขั้นตอนเดิม ไม่ต้องลบข้อมูล ไม่ต้องเพิ่ม migration

ตรวจ /api/health ให้ release เป็น P10.18-NOTIFICATION-CENTER และหน้าเว็บแสดง UI P10.18

การ์ดสรุปรอบใหม่จะใช้รูปแบบเดิม ข้อความที่ส่งสำเร็จวันนี้จะไม่ถูกส่งซ้ำหลังอัปเดต คิวที่เคยพยายามส่งแล้วจะคงข้อความและ retry key เดิมเพื่อป้องกันข้อความซ้ำ เมื่อต้องการดูสรุปปัจจุบันใช้คำสั่ง/ปุ่ม “ดูสรุปวันนี้” ใน LINE ตามเดิม

## ผลตรวจ

- ทดสอบโครงสร้าง Flex JSON จากตัวสร้างการ์ดเดิมจริง: สี/หัวการ์ด/วันที่ไทย/กล่องตัวเลข/งานค้าง/เอกสาร/สองปุ่ม/สิทธิ์ผู้รับ/ข้อความและเวลาที่ปรับได้ ผ่าน
- ทดสอบตัว Cron ส่งผ่านคิวจริงใน SQLite โดยจำลอง LINE: ยืนยันว่า payload เป็นการ์ดเดิมและมีสองปุ่ม รวมชุดทดสอบระบบแจ้งเตือน 58 จุดผ่าน
- Regression ตั้งค่าแจ้งเตือน, retry/กันซ้ำ, Recruitment, Benefits และเวอร์ชันหน้าเว็บผ่าน
- ตรวจ syntax ของ Backend/Frontend ผ่าน
- ยังไม่ได้ Deploy หรือส่งข้อความจริงไปยัง LINE จากสภาพแวดล้อมนี้ ทดสอบรูปแบบจากโครงสร้าง Flex JSON ไม่ใช่ภาพ render ใหม่จากแอป LINE
