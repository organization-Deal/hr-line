# Nakna P10.23 — หน้ารอเข้าเว็บและโหลดข้อมูล

แพตช์เฉพาะไฟล์เปลี่ยนจาก P10.22 ต้องติดตั้ง P10.22 ก่อน

## ติดตั้ง
วางทับตามโครงสร้างเดิม แล้ว Deploy ทั้ง src/ และ public/
เพิ่มไฟล์ public/ui/loading.js และ loading.css ให้ครบ
ไม่มีไฟล์ที่ต้องลบ ไม่มี migration และไม่มีการแก้ข้อมูลในฐานข้อมูล
หลัง Deploy โหลดเว็บใหม่ ตรวจเวอร์ชัน P10.23

## เปลี่ยนอะไร
- หน้ารอเข้าเว็บลดกรอบและเงาหนัก ใช้มาสคอตเดิมขยับขึ้นลงเบา ๆ
- ใช้สถานะจากการทำงานจริง: ตรวจบัญชี / ยืนยัน LINE ถ้าใช้ลิงก์ LINE / เปิดพื้นที่ทำงานหลังยืนยันบัญชี
- ไม่แสดงเปอร์เซ็นต์หรือขั้นตอนโหลดที่แต่งขึ้น ไม่เพิ่มเวลารอขั้นต่ำ
- เข้า shell หลังยืนยัน session ตามระบบเดิม ไม่ต้องรอทุกฟีเจอร์
- เพิ่ม skeleton เฉพาะเนื้อหาหน้าในการเข้าเมนูครั้งแรก รอ 180 ms ก่อนแสดงเพื่อไม่ให้กระพริบบนการเชื่อมต่อเร็ว
- เมนูและหัวเว็บยังใช้ได้ ไม่เปิด splash เต็มจอทุกครั้งที่เปลี่ยนเมนู
- ถ้ามีข้อมูลที่โหลดแล้ว หรือ dashboard cache ของบริษัทปัจจุบัน ให้คงข้อมูลไว้ขณะอัปเดต
- ถ้ารอข้อมูลเกิน 7 วินาที มีคำอธิบายตอบช้าภายในหน้า
- โหลด API ได้ไม่ครบ มีข้อความและปุ่มลองใหม่ ไม่ทำเครื่องหมายว่าข้อมูลสดแล้ว
- เพิ่ม watchdog แยกจาก app module: ถ้า app โหลดหรือเริ่มทำงานไม่สำเร็จ จะเสนอปุ่มเชื่อมต่อใหม่ที่ 12 วินาที ปุ่มทำงานได้โดยไม่ต้องรอ bindEvents ของแอป
- รองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์
- การบันทึกยังใช้ feedback และข้อป้องกันเดิม ไม่เปลี่ยน API ธุรกิจ สูตรเงินเดือน หรือกติกาส่ง LINE

## ขอบเขต
เป็นการปรับการแสดงผลระหว่างโหลด ไม่ใช่การรับรองว่า API จะตอบเร็วขึ้น
บางฟีเจอร์มีตัวโหลดเฉพาะของตัวเอง เช่น notification center, รายละเอียดพนักงาน และการโหลดใบลาเพิ่มเติม ยังคงข้อความเฉพาะฟีเจอร์ไว้
ข้อมูลเดิมที่ยังแสดงระหว่าง refresh อาจยังไม่ใช่ข้อมูลล่าสุด หากโหลดไม่ครบให้กดลองอีกครั้ง
ระบบอนุญาตให้ออกไปเมนูอื่นได้ขณะที่เมนูเดิมกำลังโหลด
ยังไม่ได้ Deploy หรือทดสอบในเบราว์เซอร์/LINE/ระบบจริง
