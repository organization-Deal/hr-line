# Nakna P10.31 — ลายเซ็น HR บนสลิปเงินเดือน

แพ็กเกจเฉพาะไฟล์ที่เพิ่ม/เปลี่ยนจาก P10.30-PAYSLIP-SEND-FIX

## ติดตั้ง
1. ใช้กับซอร์ส P10.30 ที่แก้การส่งสลิป LINE แล้ว
2. แตก ZIP แล้ววางไฟล์ทับในตำแหน่งเดิม รวมไฟล์ใหม่ src/payroll-issuer.js
3. Deploy ทั้ง src และ public ในรอบเดียวตามวิธีเดิมของโครงการ
4. เปิดหน้าเว็บใหม่ ตรวจว่าแสดง UI P10.31 และ backend P10.31-PAYSLIP-HR-SIGNATURE
ไม่ต้องลบไฟล์เดิม ไม่ต้องสั่ง migration เพิ่ม และแพ็กเกจนี้ยังไม่ได้ Deploy ให้

## วิธีตั้งค่า
Payroll → เปิดรอบเงินเดือน → เครื่องมือเพิ่มเติม → ตั้งค่าลายเซ็นบนสลิป
ใช้การตั้งค่าเอกสารชุดเดิมของบริษัท ไม่ต้องอัปโหลดลายเซ็นซ้ำหากบันทึกไว้แล้ว
ระบุชื่อ HR ผู้ออกเอกสาร ตำแหน่ง และอัปโหลด PNG/JPG จากนั้นกดบันทึก
ตั้งค่าก่อนล็อกรอบหรือสร้าง PDF ครั้งแรก เพราะระบบอาจเตรียมสลิปทันทีที่ล็อกรอบ

## พฤติกรรม
- PDF ที่สร้างใหม่มีลายเซ็น HR ฝั่งบริษัท ชื่อ ตำแหน่ง และวันที่ออกเอกสารตามเวลาไทย
- ป้ายกำกับคือ “ผู้ออกเอกสาร” ไม่ใช่การรับเงินหรือลายเซ็นของพนักงาน
- ใช้ภาพและข้อมูลชุดเดียวกันตลอดการสร้างไฟล์ใหม่หนึ่งชุด
- ลายเซ็นถูกฝังใน PDF ไม่ได้อ้างถึงภาพที่เปลี่ยนตามการตั้งค่าภายหลัง
- บริษัทที่ยังไม่ตั้งชื่อและลายเซ็น ใช้การสร้างสลิปเดิมต่อได้ หากตั้งชื่ออย่างเดียว แสดงชื่อโดยไม่สร้างลายเซ็นให้เอง
- หากมีรูปลายเซ็น ต้องระบุชื่อด้วย หากภาพเสียหรืออ่านไม่ได้จะไม่สร้างไฟล์ใหม่แบบละลายเซ็นเงียบ ๆ
- อ่านการตั้งค่าเฉพาะบริษัทของรอบเงินเดือนนั้น
- รายการยาวขึ้นหน้าใหม่ได้ ลายเซ็นไม่ทับยอดเงินหรือข้อความท้ายหน้า ชื่อ/ตำแหน่งยาวตัดบรรทัดได้
- แก้ช่องว่างก่อนกล่องรับสุทธิ เพื่อให้ “หักรวม” ไม่ถูกกล่องบัง
- สูตรคำนวณเงินเดือน จำนวนเงิน และขั้นตอนยืนยันจ่าย/เลือกผู้รับ/ส่ง LINE คงเดิม

## สลิปที่สร้างไว้ก่อนอัปเดต
ไม่เขียนทับ PDF เดิม รวมถึงไฟล์ที่สร้างแล้วแต่ยังไม่ได้ส่ง
การเปลี่ยนค่าลายเซ็นและกดสร้างสลิปซ้ำไม่ทำให้ PDF เดิมเปลี่ยน
แพ็กเกจนี้ไม่มีคำสั่งย้อนแก้สลิปเก่าหรือส่งสลิปอัตโนมัติ
