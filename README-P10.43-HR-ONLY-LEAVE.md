# P10.43 — ลากับ HR เท่านั้น

แพตช์เฉพาะไฟล์ที่เปลี่ยน สำหรับติดตั้งทับ P10.42 ให้ติดตั้ง frontend และ backend พร้อมกัน แล้วรีเฟรชหน้าเว็บด้วย Ctrl+Shift+R (เวอร์ชัน UI P10.43)

## วิธีใช้

1. Owner / Co-owner / HR Admin / HR เปิดหน้า **การลา**
2. เปิดสวิตช์ **ลากับ HR เท่านั้น** ด้านบน
3. พนักงานแจ้งประเภทลา วันที่ลา เหตุผล และเอกสารประกอบกับ HR โดยตรง
4. HR กด **บันทึกการลา** ด้านบน แล้วกรอกรายการแทนพนักงาน

เมื่อเปิดโหมดนี้ ฟอร์มออนไลน์ ลิงก์เก่า และคำขอผ่าน LINE จะบอกให้ติดต่อ HR การปิดกั้นตรวจที่เซิร์ฟเวอร์ด้วย ไม่ใช่เพียงซ่อนปุ่ม ผู้จัดการไม่สามารถใช้ช่องทางบันทึกแทนเพื่อข้ามโหมดนี้ได้

ปิดสวิตช์เพื่อกลับมาให้พนักงานยื่นออนไลน์ บริษัทเดิมเริ่มต้นในโหมดออนไลน์ ไม่มีการเปิดสวิตช์ให้อัตโนมัติ การเปลี่ยนโหมดไม่เปลี่ยนสิทธิ์ลา ยอดคงเหลือ หรือประวัติเดิม รายการที่ HR บันทึกยังใช้ขั้นตอนอนุมัติและหลักฐานเดิมของระบบ

## ฐานข้อมูล

เพิ่มตาราง company_leave_channels ผ่าน migrations/0047_hr_only_leave.sql ตามขั้นตอน migration เดิมได้ เซิร์ฟเวอร์มีการสร้างตารางแบบ idempotent เมื่อใช้งานครั้งแรกด้วย ค่าแยกตามบริษัท และการบันทึกโหมดมีการตรวจบริษัทปัจจุบัน

## ตรวจสอบแล้ว

- SQLite: 23 กรณี ครอบคลุมสิทธิ์ การแยกบริษัท ลิงก์เก่า การเปิด/ปิด การบันทึกโดย HR และการสลับโหมดระหว่างส่งคำขอ
- Chromium: สวิตช์และการย้อนค่าหากบันทึกล้มเหลว สิทธิ์ HR/ผู้จัดการ ฟอร์มพนักงาน และหน้าจอมือถือ
- Regression ฟอร์มลาเดิม 9 กรณี และตรวจเวอร์ชัน release

ไม่ได้ส่งข้อความ LINE จริงหรือเปลี่ยนการตั้งค่าบริษัท production ระหว่างทดสอบ
