# Nakna P10.8 — Simple Gmail Recruitment Setup

## ปัญหาเดิม
การเชื่อมบัญชีสำเร็จแล้ว แต่ผู้ใช้ต้องรู้จัก Gmail Search Query, `To`, `Label`, `Sync` และรูปแบบประโยค `to:...` เพื่อเปิดรับใบสมัคร ทำให้กรอกผิดได้ เช่นใส่ `in:inbox to:hr.info@...` ลงในช่องผู้รับ และระบบสร้าง Query ผิดเป็น `to:in:inbox...`

## หลังแก้
หน้าตั้งค่า Gmail รับสมัครงานมีโหมด **ตั้งค่าแบบง่าย** เป็นค่าเริ่มต้น:

- แสดงบัญชี Gmail ที่เชื่อมอยู่ เช่น `hr.info@dealinvests.com` อัตโนมัติจากหัวหน้าต่าง ไม่ Hardcode
- กด **เปิดรับใบสมัครจาก Gmail นี้** เพียงปุ่มเดียว
- ระบบใช้ฟอร์มเดิมกรอก **Recipient Mode, To = อีเมลบัญชี (ไม่ใช่ Query), ย้อนหลัง 30 วัน, เปิด Inbox, Sync อัตโนมัติ** แล้วสั่งกดบันทึกผ่าน handler เดิม
- อีเมลเข้า **คิวคัดกรอง** ไม่เข้า Candidate อัตโนมัติ; ไม่ตอบกลับอีเมล และไม่ลบเมลใน Gmail
- มีปุ่ม **ตัวเลือกขั้นสูง** สำหรับอ่านจากผู้ส่ง / Label / Query / ทุก Inbox และแก้ค่าอื่นหากต้องการ
- ไม่ยิง API เพิ่มเอง ไม่ Sync ทันทีจนกว่าผู้ใช้จะกด Sync ใน Recruitment; ไม่เปลี่ยนการเชื่อม Google หลัก

### ความปลอดภัยและการอ่านอีเมล
โหมดเริ่มต้นอ่าน **เฉพาะอีเมลที่ส่งถึงบัญชีที่เชื่อมโดยตรง** ในช่วง 30 วัน ไม่ใช่เปิดอ่านทุก Inbox แบบไม่มีเงื่อนไข. หากรับใบสมัครผ่าน Alias/Forwarded mail ให้ใช้ตัวเลือกขั้นสูงโดยได้รับความเห็นชอบจากผู้ดูแล เพื่อป้องกันการนำเข้าเมลส่วนตัว.

## ติดตั้ง
แพ็กนี้ต่อจาก P10.x และ P10.7 ได้ หรือจะติดตั้งโดยไม่ใช้ P10.7 ก็ได้ เพราะทำหน้าที่คนละส่วน.

1. เก็บ branch สำรองหรือทำบน Staging ก่อน
2. คัดลอก `public/ui/p10-8-recruitment-simple.js` และ `public/ui/p10-8-recruitment-simple.css` ไปวางใน Repository เดิม; คัดลอก `tools/apply-p10.8.mjs` และ `tools/rollback-p10.8.mjs` เพิ่ม
3. จาก root ของ Repo รัน:

```
node tools/apply-p10.8.mjs --dry-run
node tools/apply-p10.8.mjs
npm run check
npx wrangler deploy
```

ตัวติดตั้งแก้ **public/index.html เพียงสองบรรทัด** ไม่เขียนทับ `public/app.js` หรือ `src/index.js` ไม่ต้อง Migration.

**GitHub Web UI:** หลังอัปสองไฟล์ UI ลง `public/ui/` เพิ่มต่อไปนี้ก่อน `</head>` ของ `public/index.html` ปัจจุบัน (ห้ามใช้ไฟล์ HTML เก่าไปทับ):

```html
<link rel="stylesheet" href="/ui/p10-8-recruitment-simple.css?v=P10.8-1" />
<script defer src="/ui/p10-8-recruitment-simple.js?v=P10.8-1"></script>
```

## ใช้งาน
เข้า Recruitment → บัญชีรับสมัครงานที่เชื่อม → **เลือกแหล่งเมล** → กด **เปิดรับใบสมัครจาก Gmail นี้** → หากบันทึกสำเร็จ กด **Sync** ครั้งแรกที่บัญชี Gmail แล้วดูคิวคัดกรอง

หากต้องการเลือกอีเมลตาม Label หรือทุก Inbox ให้กด **ตัวเลือกขั้นสูง**. หากฟอร์มหรือ Server ไม่ตรงกับรุ่นที่ตรวจมา โหมดง่ายจะไม่เดาข้อมูล และเปิดตัวเลือกขั้นสูงให้ตรวจแทน.

## ข้อจำกัด
UI addon นี้ใช้ปุ่ม Save และ validation ของระบบเดิม ไม่ควรตีความว่าบันทึกสำเร็จจากการคลิกอย่างเดียว. ยังไม่ได้ทดสอบ OAuth / Gmail API จริงบน Production; ตรวจด้วยบัญชี HR ใน Staging ก่อนและไม่ให้ระบบ Sync เมลที่ไม่เกี่ยวข้องโดยไม่ตรวจการตั้งค่า.
