# Nakna P10.7 — Recruitment Gmail Account Picker Bridge

## อาการที่แก้

- ใต้ **บัญชีรับสมัครงานที่เชื่อม** มี `hr.info@dealinvests.com` แล้ว แต่สถานะ **ตั้งแหล่งเมลก่อน / ยังไม่เคย Sync**
- ตัวกรอง **ทุกบัญชี Gmail** ในคิวคัดกรองแสดงแต่บัญชีที่ *เคยนำเข้าอีเมล* เช่นบัญชี Google หลัก ไม่แสดงบัญชี HR ที่เพิ่งเชื่อม
- กด **ตั้งค่า Google หลัก** แล้วเห็นหน้าจอ query ของ Google หลัก จึงเข้าใจผิดว่ากำลังตั้งค่าอีเมล HR

**สาเหตุ:** ตัวกรองคิวกับการเชื่อม/ตั้งค่าบัญชีเป็นคนละหน้าที่กัน และบัญชี HR ยังไม่มีข้อมูลในคิวนำเข้า

## การเปลี่ยนแปลง

1. เพิ่มบัญชี Gmail รับสมัครงานที่เชื่อมอยู่ใน Dropdown ตัวกรอง แม้ยังไม่ได้ Sync ครั้งแรก (อ่านจาก UI ของ Workspace ปัจจุบัน ไม่ Hardcode อีเมล)
2. ใต้ตัวกรองขึ้นข้อความสถานะ Gmail ที่เลือก พร้อมปุ่ม **ตั้งค่าเมล [บัญชี]**
3. กดปุ่มนี้จะเรียก action **เลือกแหล่งเมล** ของบัญชีเดิม จึงคงการตรวจสิทธิ์และขั้นตอนเดิมของระบบ ไม่แทรก API หรือเชื่อมบัญชีแทนผู้ใช้
4. ไม่ปรับ Google หลัก ไม่ย้ายเมลจากบัญชีส่วนตัว ไม่เปลี่ยน Candidate/Pipeline เดิม

**ข้อจำกัด:** P10.7 เป็น Frontend safety patch สำหรับการเลือกและนำทางไปตั้งค่าเท่านั้น ไม่แก้ API อ่าน Gmail, OAuth, backend Sync หรือโควตา Google หากกดตั้งแหล่งเมลแล้ว Sync ยังไม่ได้ ต้องตรวจ error ของ API บนระบบจริงร่วมกับไฟล์ `public/app.js` และ `src/index.js` จาก Repository เวอร์ชันล่าสุด

## วิธีติดตั้ง (ต่อจาก P10.x ใช้ได้กับ P10.4/P10.5/P10.6 เพราะไม่ทับไฟล์หลัก)

1. เก็บ branch สำรองก่อน
2. วางไฟล์ตามโฟลเดอร์ใน ZIP ใน Root ของ Repository **โดยไม่ลบไฟล์เดิม**
3. ใน Terminal ที่ Root รัน:

```bash
node tools/apply-p10.7.mjs --dry-run
node tools/apply-p10.7.mjs
npm run check
npx wrangler deploy
```

**สำหรับ GitHub Web UI:** อัปสองไฟล์ใหม่ใน `public/ui/` แล้วเพิ่มสองบรรทัดนี้ก่อน `</head>` ของ `public/index.html` เวอร์ชันใช้งานจริง:

```html
<link rel="stylesheet" href="/ui/p10-7-recruitment-gmail.css?v=P10.7-1" />
<script defer src="/ui/p10-7-recruitment-gmail.js?v=P10.7-1"></script>
```

ไม่ต้อง Migration ไม่ต้องแก้ Secret และ **อย่าอัปไฟล์ `public/index.html` จากแพตช์รุ่นเก่ามาทับ**

## ขั้นตอนทดสอบหลัง Deploy

1. เปิด Recruitment ในบริษัทเดิม ตรวจว่า **บัญชี HR เชื่อมอยู่** และปุ่ม **เลือกแหล่งเมล** เปิดได้
2. คิวคัดกรอง → ตัวกรอง Gmail จะมีบัญชี HR เพิ่ม แม้ยังมี 0 อีเมล
3. กด **ตั้งค่าเมล HR** จากตัวช่วย → เลือกเงื่อนไขรับเมลเฉพาะที่ตั้งใจ แล้วบันทึก
4. กด **Sync** ที่การ์ด Gmail HR เอง; เมื่อเชื่อมและตั้งค่าเรียบร้อยแล้วให้ยืนยันว่าเมล HR ที่ถูกต้องปรากฏในคิว
5. ต้องไม่เกิดการนำเข้าเมลส่วนตัวจาก Gmail หลักโดยไม่มีการตั้งค่า/ยืนยันของผู้ใช้
6. ถ้า Sync ยังถูกล็อกอยู่ ให้เปิด Console หรือดู Error ของบัญชี HR แล้วส่งผลพร้อม `public/app.js` และ Backend ล่าสุดเพื่อแก้เส้นทางนี้ต่อโดยไม่เดา

### Undo

```bash
node tools/rollback-p10.7.mjs
npx wrangler deploy
```

ลบสอง tag ที่เพิ่งเพิ่มใน HTML เท่านั้น (ไฟล์ JS/CSS ที่ไม่ได้ถูกเรียกจะไม่ทำงาน)
