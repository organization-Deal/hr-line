# Nakna P10.17 — ศูนย์การแจ้งเตือนและแก้ระบบส่ง LINE

ไฟล์ชุดนี้เป็นโค้ดที่เปลี่ยนจาก P10.16 วางทับตามโฟลเดอร์เดิมในโปรเจกต์ ไม่ต้องลบข้อมูลหรือไฟล์ระบบอื่น

## วิธีอัปเดตให้ระบบส่งจริงเปลี่ยนด้วย

1. นำไฟล์ `src/` และ `public/` ใน ZIP วางรวมกับโปรเจกต์เดิม ต้องนำ `src/notification-center.js` ไปด้วย
2. Deploy **Worker ทั้งโปรเจกต์** ผ่านระบบเดิม การอัปโหลดเฉพาะหน้าเว็บจะไม่เปลี่ยน Cron/ระบบส่งข้อความ
3. ตรวจ `/api/health` ต้องได้ release `P10.17-NOTIFICATION-CENTER` และหน้าเว็บต้องแสดง `UI P10.17`
4. เปิดเมนู **การแจ้งเตือน** หาก Cron ทำงานจะเห็นเวลาทำงานล่าสุด ตั้ง Cron ของ Worker เป็น `* * * * *` (ทุกนาที) โดยใช้ DB, secrets และ LINE integration เดิม ไม่ต้องเอา wrangler.jsonc จากที่อื่นมาทับ
5. กด **ทดสอบส่งถึงฉัน** จากบัญชี HR/Owner ที่เชื่อม LINE ของบริษัทนี้ แล้วดูทั้งประวัติและแชต LINE หากผิดพลาดหน้าประวัติจะแสดงสาเหตุ
6. รอรอบเวลาที่ตั้งไว้เพื่อยืนยันการส่งอัตโนมัติจริง การกดทดสอบสำเร็จยืนยันเฉพาะทางส่ง LINE ไม่ยืนยันว่า Cron ทำงาน

ฐานข้อมูลใหม่มีเฉพาะตารางตั้งค่า คิวส่ง และสถานะ Cron ระบบสร้างให้อัตโนมัติเมื่อเปิดเมนูหรือ Cron เริ่มทำงาน หากกระบวนการของคุณใช้ migration ให้รัน `0042_notification_center.sql` ผ่านขั้นตอนเดิมได้ คำสั่งเป็น CREATE IF NOT EXISTS และไม่มี DROP/DELETE ข้อมูลพนักงาน

## สิ่งที่แก้

- เพิ่ม `bangkokClock()` ที่ Cron และคำสั่ง HR เรียกใช้ แต่ไม่มีนิยามในโค้ดชุดเดิม
- เปลี่ยนงานแจ้งเตือนตามเวลามาใช้ตัวส่งกลางเดียว เลิกเรียกตัวเตือนเช็กอิน/สรุป HR เดิมซ้อนกัน รวมถึงสรุป HR เดิมเวลา 08:00 ส่วนงาน Recruitment และงานประจำวันอื่นยังอยู่
- ตั้งเวลา วัน ข้อความ เปิด/ปิด และเลือกผู้รับสรุปได้จากเมนูเดียว ย้ายตัวตั้งเตือนเช็กอินออกจากหน้าตั้งค่าการเช็กอิน
- 5 ประเภท: เช็กอิน, เช็กเอาต์, สรุป HR, สรุปผู้บริหาร, งานรออนุมัติ
- เตือนเช็กอินและสรุป HR เปิดเป็นค่าเริ่มต้น โดยเก็บสถานะปิดและข้อความเช็กอินเดิมไว้ อีก 3 ประเภทปิดไว้จนกว่าจะเปิดเอง
- เช็กอินเฉพาะพนักงานที่ทำงานวันนี้ ถึงเวลาเริ่มกะ และยังไม่เช็กอิน ข้ามคนลา วันหยุด ไม่มี LINE และสถานะพนักงานที่ไม่มีสิทธิ์
- เช็กเอาต์เฉพาะคนที่เช็กอินแล้ว ยังไม่เช็กเอาต์ และถึงเวลาเลิกกะ รองรับรอบกะที่เริ่มและจบในวันเดียวกัน
- ส่งสรุปให้ผู้รับที่ระบบเดิมยืนยันสิทธิ์ HR ไว้ ผู้บริหารจำกัด Owner/Co-Owner ตรวจสิทธิ์ใหม่ทุกครั้งก่อนส่งและบันทึกตัวเลือก
- จดคิวและผลส่งใน DB แยกบริษัท/วัน/ประเภท/ผู้รับ ล็อกก่อนส่ง กัน Cron ซ้อน และใช้ LINE retry key กับข้อความเดิมเมื่อลองใหม่
- ลองส่งใหม่สำหรับ network error, timeout, HTTP 408/429/5xx สูงสุด 6 ครั้ง โดยเว้นระยะ การตั้งค่า token ผิด/สิทธิ์ส่งผิดจะแสดงข้อผิดพลาดให้แก้
- Cron พลาดนาทีตรงยังส่งชดเชยได้: เช็กอิน/เช็กเอาต์ 60 นาที, HR 5 ชั่วโมง, ผู้บริหาร 3 ชั่วโมง, งานรออนุมัติ 2 ชั่วโมง นับจากเวลาตั้งในวันนั้น ไม่มีการส่งย้อนหลังข้ามวัน
- จำกัดการพยายามส่งครั้งละ 60 รายการ และส่งที่เหลือใน Cron ถัดไปภายในช่วงส่ง กรองพนักงานครั้งละไม่เกิน 1,000 รายการ/บริษัท/ประเภท
- ตรวจบันทึกส่งสำเร็จจากระบบเดิมในวันเดียวกันด้วย ป้องกันส่งซ้ำระหว่างอัปเกรด
- ปุ่มทดสอบส่งได้เฉพาะบัญชีผู้กด ไม่รับค่าผู้รับจาก request และไม่แสดง token/LINE ID ใน API ประวัติ
- คำสั่ง LINE “สถานะสรุป HR” และ API สถานะเดิมอ่านเวลาตั้งและผลส่งของระบบใหม่ด้วย

สถานะ “LINE รับข้อความแล้ว” คือ LINE API ยอมรับคำขอ ไม่ใช่หลักฐานว่าโทรศัพท์รับหรือผู้รับอ่านแล้ว ผู้รับที่บล็อก OA อาจไม่เห็นข้อความ ส่วนโควตาหรือ token ต้องตรวจจากผลจริงของบริษัท

## การทดสอบ

รันจาก root ของโปรเจกต์ด้วย Node และ Python 3:

```
node --check src/index.js
node --check src/notification-center.js
node --check public/app.js
node --check public/notifications.js
node tests/test-p10.17-notifications.mjs
node tests/test-p10.17-ui.mjs
node tests/test-p10.10.mjs
node tests/test-p10.11.mjs
node tests/test-p10.12-recruitment.mjs
node tests/test-p10.13-benefits.mjs
node tests/test-release-version.mjs
```

ทดสอบระบบส่ง 56 จุดด้วย SQLite จริงและจำลอง LINE รวมวันเวลาไทย การพลาดนาทีส่ง retry/idempotency/ล็อกซ้อน ข้ามคนเช็กอิน/ลา/วันหยุด ประเภทเช็กเอาต์ การแยกบริษัท การเปลี่ยนบัญชี LINE และทดสอบถึงตนเองเท่านั้น พร้อม regression ของ Recruitment/สวัสดิการ/Attendance/เวอร์ชันหน้าเว็บ

ทดสอบ UI ระดับ state และ HTML รวมการบันทึก/สิทธิ์/การเปลี่ยนบริษัท/escape ชื่อ ยังไม่ได้ตรวจภาพในเบราว์เซอร์รอบนี้เพราะสภาพแวดล้อมไม่มี Chromium และดาวน์โหลดไม่สำเร็จ ยังไม่ได้ Deploy หรือส่ง LINE ไปยังระบบจริงจากสภาพแวดล้อมนี้
