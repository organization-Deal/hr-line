# P10.34 — จัดตำแหน่งปุ่ม Payroll

วางทับ P10.33 แล้ว Deploy public ทั้งชุดในแพตช์

- แก้ไขรอบ / คำนวณใหม่ / ลบรอบ อยู่ด้านขวาของชื่อรอบเงินเดือน
- เพิ่มหลายคน / เพิ่มรายการรายคน อยู่เหนือรายชื่อพนักงาน
- ตั้งค่าลายเซ็น อยู่ข้างตั้งค่า Payroll ด้านบน
- เครื่องมือสร้างสลิป ส่งออก และปลด Lock ยังแสดงตามสถานะรอบเดิม
- รองรับการเรียงปุ่มบนหน้าจอเล็ก

ไม่ต้องแก้ฐานข้อมูลหรือคำนวณเงินเดือนใหม่
ตรวจ syntax และชุดทดสอบ Payroll P10.21, P10.22, release label และการจัดกลุ่มปุ่มแต่ละสถานะผ่าน ยังไม่ได้ตรวจหน้าจอในเบราว์เซอร์จริง
