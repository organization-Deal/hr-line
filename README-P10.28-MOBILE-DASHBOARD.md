# Nakna P10.28 — Dashboard มือถืออ่านเร็วขึ้น

ใช้ทับ P10.25, P10.26 หรือ P10.27 ได้ แพ็กนี้รวมส่วนแก้โหลดช้าและ Employee Service จาก P10.27 แล้ว เป็นเฉพาะไฟล์เปลี่ยนจากฐาน P10.25 ไม่ใช่ Full source

วิธีอัปเดต
1. วางไฟล์ public/ และ src/ ทับโฟลเดอร์เดิมตามชื่อ ห้ามซ้อน public/public
2. Deploy Worker พร้อม static assets ไม่ต้องลบไฟล์เดิมหรือเพิ่ม migration สำหรับแพ็กนี้
3. เปิดหน้าใหม่แล้วตรวจป้ายเวอร์ชันในเมนูด้านข้างต้องเป็น UI P10.28
4. tests/ เป็นไฟล์ตรวจโค้ด ไม่ต้องตั้งเป็นเว็บไซต์

การเปลี่ยนหน้า Dashboard ที่จอกว้างไม่เกิน 760px
- เอาหัวข้อซ้ำและคำเกริ่นออกจากพื้นที่เนื้อหา คงชื่อบริษัท วันที่ และสถานะอัปเดตแบบย่อ
- งานที่รอจัดการเหลือชื่องานและจำนวน ตัดคำอธิบายซ้ำแต่คงปลายทางและจำนวนเดิม
- ใช้ไอคอน SVG แทนอีโมจิลูกศรที่ iPhone แสดงเป็นกล่องสี
- การ์ดสถานะทีมเหลือชื่อและตัวเลข ลดขนาดกรอบและช่องว่าง โดยยังแตะดูรายชื่อได้
- ย้ายข้อมูลมาสาย จำนวนพนักงาน และวิธีนับไปไว้ใน "รายละเอียดทีม" ซึ่งเริ่มต้นพับไว้ กดเปิดด้วยนิ้วหรือคีย์บอร์ดได้
- ถ้าข้อมูลยืนยันว่าไม่มีตารางงานวันนี้ แสดงสถานะวันหยุดหรือไม่มีตารางงาน แทนการ์ดเลขศูนย์ 4 ใบ
- หากมีคนลงเวลานอกตารางในวันหยุด ยังคงแจ้งจำนวนและเปิดรายชื่อได้
- ข้อมูลที่ยังไม่ตรงกันจะไม่ถูกแสดงเป็นสถานะไม่มีตารางงาน
- คงข้อมูลเดิมและข้อความเตือนเมื่อรีเฟรชไม่สำเร็จหรือกำลังอัปเดต
- การย่อรายละเอียดอยู่ใน media query เฉพาะมือถือ จอคอมยังแสดงคำอธิบายเดิม

รวมการปรับปรุงจาก P10.27
- เปลี่ยนหน้าแล้วกลับด้านบนทันที ปุ่มและสวิตช์มีพื้นที่กดใหญ่ขึ้น ช่องกรอกบนมือถือใช้ 16px
- ลด GET ที่ซ้ำกันระหว่างกำลังโหลด แยกผู้ใช้และบริษัท ยกเลิกการใช้คำขอร่วมหลังเขียนข้อมูล
- ไม่ preload ข้อมูลพนักงานบนจอมือถือ/2G/โหมดประหยัดข้อมูล
- Dashboard อ่านเฉพาะคอลัมน์ที่ใช้ และรวมวันลา/ตาราง/วันหยุดใน batch แรก
- รวม Employee Service, กรอบวันหยุด, layout สิทธิ์ และแท็บรอจัดการจาก P10.26

การตรวจรอบนี้
- 23 checks สำหรับ compact Dashboard: จำนวนงานเดิม, ปลายทาง, การพับรายละเอียด, วันหยุดที่มีคนลงเวลา, escaping, ข้อมูลเก่า/ไม่ตรงกัน และ renderer จริง
- ผ่าน regression Dashboard 76, mobile/performance 30, Employee Service 44, Loading 28, full LINE preview 25, Notifications 66 รวม 292 checks พร้อม syntax/release checks
- ไม่ได้ Deploy หรือส่ง LINE จริง และยังไม่ได้ตรวจภาพหลังแก้บน iPhone/Safari จริง
