# P10.50 ข้อมูลเงินเดือนในลิงก์เชิญ
ลงทับ P10.49 ทั้ง src/ และ public/ แล้วเผยแพร่ใหม่ ไม่ต้องเปลี่ยนลิงก์เชิญเดิม รีเฟรชหน้าลิงก์ก่อนกรอก

เพิ่มเลขบัตรประชาชน ธนาคาร ชื่อบัญชี และเลขบัญชีธนาคารในแบบฟอร์มเชิญพนักงาน ทุกช่องใหม่เว้นว่างได้ หากเริ่มกรอกบัญชีต้องครบทั้ง 3 ช่อง ไม่เปิดให้พนักงานกำหนดเงินเดือน
เลขบัตรตรวจรูปแบบ 13 หลัก (ไม่ได้ยืนยันตัวตนหรือทะเบียนราษฎร), เลขบัญชีตรวจตัวเลข 6–20 หลัก (ไม่ได้ตรวจเจ้าของบัญชีกับธนาคาร) รองรับขีด/ช่องว่างและเก็บเลขศูนย์นำหน้า
national_id บันทึกลง employees, ข้อมูลธนาคารบันทึกลง employee_payroll_profiles ด้วย batch เดียวกับสร้างพนักงาน จึง rollback ทั้งคู่เมื่อบันทึกบัญชีล้มเหลว โปรไฟล์ใหม่ใช้ค่าเริ่มต้นเงินเดือน 0 ให้ HR ตั้งต่อ ไม่รับ base_salary จาก public request
ข้อมูลใหม่ไม่ได้เพิ่มลง response หรือ localStorage
