# P10.33 — ปุ่มเครื่องมือรอบเงินเดือนด้านบน

ใช้วางทับ P10.32 แล้ว Deploy public พร้อมกัน

- ย้ายเครื่องมือทั้งหมดมาแสดงใต้ชื่อรอบเงินเดือน ไม่ต้องเปิดเมนูพับ
- ปุ่มลบรอบแสดงเฉพาะฉบับร่างและรอตรวจ โดยยังถามยืนยันและใช้การตรวจสิทธิ์/เอกสารจากระบบเดิม
- รอบยกเลิกแสดงข้อความถูกต้อง แทนข้อความว่าจ่ายและส่งแล้ว
- ปรับปุ่มให้เรียงได้ทั้งหน้าจอคอมพิวเตอร์และมือถือ

ไฟล์ระบบที่เปลี่ยน: public/app.js, public/index.html, public/release.js, public/ui/payroll-workflow.css
ไม่ต้องแก้ฐานข้อมูล และไม่ต้องคำนวณเงินเดือนใหม่

ตรวจ syntax, ชุดทดสอบ Payroll P10.21/P10.22, release label และการแสดงเครื่องมือแต่ละสถานะผ่านแล้ว ยังไม่ได้ทดสอบในเบราว์เซอร์จริง
